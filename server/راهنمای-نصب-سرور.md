# نصب سرور روی ویندوز سرور (قدم‌به‌قدم)

این سرور اطلاعات همه گوشی‌ها را یکی می‌کند و از آن نسخه پشتیبان روزانه می‌گیرد.

## ۱) وارد سرور شوید
با برنامه Remote Desktop (Remote Desktop Connection) با آی‌پی، نام کاربری و رمزی که میهن‌وب داده وارد ویندوز سرور شوید.

## ۲) نصب Node.js
1. داخل سرور مرورگر را باز کنید و به nodejs.org بروید.
2. نسخه LTS را دانلود و نصب کنید (همه مراحل Next).
3. بعد از نصب، یک بار سرور را Restart کنید یا پنجره‌های باز را ببندید.

## ۳) گذاشتن فایل‌های سرور
1. پوشه `server` (همین پوشه) را در درایو C کپی کنید و اسمش را `accessory-server` بگذارید؛ آدرس نهایی: `C:\accessory-server`
   (کپی از کامپیوتر خودتان به سرور با Copy و Paste داخل Remote Desktop انجام می‌شود).
2. فایل `config.json` را با Notepad باز کنید و به‌جای `CHANGE-THIS-KEY` یک کلید دلخواه بنویسید (مثلاً یک رمز طولانی). این کلید را در برنامه هم وارد می‌کنید.
   اگر پورت ۳۱۰۰ در سرور شما استفاده شده، عدد port را عوض کنید.

## ۴) روشن کردن
روی `start.bat` دوبار کلیک کنید. باید پیام «سرور روشن شد» نمایش داده شود. این پنجره را نبندید.

## ۵) باز کردن پورت (Firewall)
روی دکمه Start راست‌کلیک کنید ← Windows PowerShell (Admin) یا Command Prompt (Admin) و این دستور را بزنید (اگر پورت را عوض کردید، عدد را هم عوض کنید):

    netsh advfirewall firewall add rule name="AccessoryServer" dir=in action=allow protocol=TCP localport=3100

اگر در پنل میهن‌وب هم فایروال یا باز کردن پورت وجود دارد، پورت ۳۱۰۰ را آنجا هم باز کنید.

## ۶) تست
در مرورگر گوشی بزنید: `http://آی‌پی-سرور:3100/ping`
اگر کلمه `ok` آمد، سرور آماده است.

## ۷) روشن شدن خودکار بعد از ری‌استارت
در همان Command Prompt (Admin) این دستور را بزنید:

    schtasks /create /tn "AccessoryServer" /tr "C:\accessory-server\start.bat" /sc onstart /ru SYSTEM

## ۸) اتصال برنامه
در برنامه: ⚙ ← «اتصال به سرور»:
- آدرس سرور: `http://آی‌پی-سرور:3100`
- کلید دسترسی: همان کلیدی که در config.json نوشتید
- نام شما: نام همان کاربر (مثلاً نام پرسنل)
سپس «ذخیره و اتصال». نقطه سبز کنار ⚙ یعنی متصل است. همین کار را روی گوشی همکاران انجام دهید.

## نکات
- اطلاعات در `C:\accessory-server\data` ذخیره می‌شود. نسخه پشتیبان روزانه در `data\backups` است (۳۰ روز آخر).
- اگر گوشی آنلاین نباشد، کار می‌کند و بعداً خودکار همگام می‌شود.
- این اتصال رمزنگاری‌شده (https) نیست. کلید دسترسی را ساده نگذارید و آن را فقط به پرسنل بدهید.
